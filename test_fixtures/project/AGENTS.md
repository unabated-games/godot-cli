### `godot/ui/Button`

- **Class:** `Button`
- **Inherits:** `BaseButton`
- **Tags:** ui, control, input, godot

Standard Godot push button control.

**When to use:** Simple debug or editor UI where no project button manifest applies.

**When not to use:** Player-facing menus and HUD — prefer project catalog entries.

**Signals**

- `pressed` — Emitted when the button is toggled on (button is pressed down).
- `button_down` — Emitted when the button starts being held down.
- `button_up` — Emitted when the button stops being held down.

**Related:** `godot/ui/BaseButton`
